# 实测记录：2026-10-07 样片 v1（13 张照片 → 96.9 秒成片）

- 环境：Windows 11 / RTX 4050 Laptop 6GB / ComfyUI / Wan2.1-VACE-1.3B-Q4_K_M (GGUF) / ffmpeg 7.1
- 成片：1920x1080 / 30fps / 96.90 秒 / 97.7 MB；音轨 loudnorm I=-16，实测 -14.8 LUFS
- 线上：B站 BV16bHy6mEqn（公开发布，素材为公开授权图库）

## 耗时（逐步实测）

- 选图：Openverse 抓取 42 张候选，189 秒
- 修复：Real-ESRGAN x4，15 张共 106 秒（约 7 秒/张）
- 活化：13 条 × (551–603) 秒，合计 123 分钟（单条约 9–10 分钟）
- 升清+插帧+慢放：13 条 × (118–127) 秒，合计 26 分钟
  - 升清约 67 秒/条（Real-CUGAN x2，约 1.2 秒/帧 × 61 帧）
  - 重建约 53 秒/条（scale + setpts 1.55x 慢放 + minterpolate 到 30fps + 尾帧停留）
- 总装：ffmpeg 一次成型 54.2 秒（15 段 xfade 链 + 4 条字幕叠加 + 音频处理）
- 换算：每张照片全流程约 11.7 分钟机器时间

## 质检

- 13/13 条片段 PASS：首帧锚定 diff ≤ 15 且最像帧 ≤ 2；
  相邻帧差均值 0.798–14.021（依镜头类型：静坐镜头小、奔跑/推近镜头大）
- 成片抽帧 3 处 + 转场边界 3 处目检正常

## 翻车与修复（如实）

1. Openverse 直连不通 → 走本机代理解决。
2. 配乐站 FreePD 已关站 → 改用 Wikimedia Commons（公有领域）。
3. **Real-ESRGAN 的 `-s 2` 输出拼贴错图** → 影片升清改用 Real-CUGAN x2（逐帧约 1.2 秒）；
   发现时已处理到第 1 条一半，立即中止删除重来（重做损失约 8 分钟，估算）。
4. 有一条竖幅照片初版用两侧模糊填充不好看 → 按脸部重裁特写后重渲（+554 秒重做成本）。
5. 字幕初版字号偏小且压在主体上 → 放大字号 + 移到画面下三分位。
6. 大面积渐变的天空：1080p 抽帧复核未见明显色带；全屏细看渐变处可能仍
   有极轻微断层（源素材特性，如实记录）。
7. 结尾一条为缓慢推近镜头，画面会略柔（有意保留的观感）。

## 已知边界

- 每条片段固定 61 帧 @16fps 源 → 约 6.8 秒/条；整片约 7.5 秒/张（13 张 ≈ 97 秒）
- 6GB 显存下批量务必串行
- 照片修复用 `-s 4`（约 7 秒/张）；视频逐帧升清 1.2 秒/帧
